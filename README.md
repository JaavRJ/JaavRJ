## 🚀 Featured Projects

### 🚂 RailSense
> AI-Powered platform that transforms static metro maps into interactive analytics dashboards — **Open Source Winner @ Hackathon Mobility & AI 2025**

`FastAPI` `Next.js 14` `React` `TypeScript` `PyTorch` `EasyOCR` `OpenCV` `Docker Compose` `Recharts`

**Role: Tech Lead** — System architecture design, backend and analytical frontend development. Computes a **Passenger Happiness Index (PHI)** per station and line across 7 weighted categories (security, punctuality, cleanliness, comfort, communication, technical failures, saturation). Hyper-scalable to any railway system worldwide.

[![Repo](https://img.shields.io/badge/View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/AxolutionsDevs/MobilityAI-Hackaton)

---

### 💹 NobaTrade
> Institutional-grade High Frequency Trading (HFT) Crypto Arbitrage Engine.

`Java 21` `Spring Boot 3` `Next.js 14` `Docker` `SSE` `BigDecimal` `WebSockets`

Event-driven architecture connecting simultaneously to **Binance, Kraken, Coinbase, Bitfinex and OKX**. Normalizes order books in real time and evaluates spatial and triangular arbitrage strategies. Zero floating-point precision errors via `BigDecimal`. Automated Circuit Breaker for institutional risk management and a live Engine Cockpit UI.

[![Repo](https://img.shields.io/badge/View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/JaavRJ/coding-challenge-mexico)

---

### 📖 BDUM — Brillo de una Estrella Muerta
> Immersive digital reading experience for a serialized novel — deployed on Firebase.

`React` `TypeScript` `Firebase` `Firestore` `Cloudinary` `Quill` `CSS Animations`

Full-featured Kindle-style reading platform with dual reading modes (horizontal paginated / vertical scroll), real-time annotation sync via Firestore, author notes system, Google Auth, role-based admin panel with rich-text chapter editor, newsletter system, easter egg puzzle pages, and a generative star background. All deployed on Firebase Hosting.

[![Repo](https://img.shields.io/badge/View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/JaavRJ/supernobaconb)

---

### 🍎 UxerSii
> Cross-platform app to reduce food waste in CDMX — **3rd Place Best Prototype IPN 2024**

`Django` `React` `REST API` `Python`

Connects local businesses and users to give a better destination to food that would otherwise be wasted. Scalable Django REST backend with a modern React frontend. Full-stack RESTful architecture.

[![Repo](https://img.shields.io/badge/View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/DevSolutionsCo/UxerSii)
